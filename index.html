Antes de empezar

Windows Forms es la forma clásica de hacer programas con ventanas en C#. Dibujas los controles y luego escribes el código que responde a lo que hace el usuario.

  1. Crea el proyectoEn Visual Studio: Crear proyecto → Aplicación de Windows Forms (.NET).
  2. Arrastra controlesDel Cuadro de herramientas al formulario en la vista Diseño.
  3. Configura propiedadesSelecciona el control y edita la ventana Propiedades. Ponle un nombre claro (btnSaludar, txtNombre).
  4. Escribe el eventoDoble clic en el control crea su evento principal (en un botón, Click). Ahí va tu código.
Convención de nombres: usa un prefijo según el tipo: btn botón, txt TextBox, lbl Label, cmb ComboBox, lst ListBox, chk CheckBox, rdb RadioButton, dgv DataGridView.

Convertir y validar datos

Todo lo que escribe el usuario en un TextBox es texto (string). Para operar con números hay que convertirlo, y conviene hacerlo con TryParse para que el programa no se caiga.

private void btnSumar_Click(object sender, EventArgs e)
{
    if (double.TryParse(txtA.Text, out double a) &&
        double.TryParse(txtB.Text, out double b))
    {
        lblResultado.Text = "Resultado: " + (a + b);
    }
    else
    {
        MessageBox.Show("Escribe solo números.", "Dato inválido",
            MessageBoxButtons.OK, MessageBoxIcon.Warning);
        txtA.Focus();
    }
}

Mini proyecto: promedio de calificaciones

Crea tres TextBox (txtP1, txtP2, txtP3), un botón btnCalcular y un Label lblResultado.

private void btnCalcular_Click(object sender, EventArgs e)
{
    if (!double.TryParse(txtP1.Text, out double p1) ||
        !double.TryParse(txtP2.Text, out double p2) ||
        !double.TryParse(txtP3.Text, out double p3))
    {
        MessageBox.Show("Revisa las calificaciones.");
        return;
    }

    double promedio = (p1 + p2 + p3) / 3;
    lblResultado.Text = $"Promedio: {promedio:F1}";
    lblResultado.ForeColor = promedio >= 70 ? Color.LightGreen : Color.Tomato;
}

Retos para practicar

1) Agrega un botón Limpiar que vacíe los campos. 2) Permite solo números en los TextBox con KeyPress. 3) Muestra "Aprobado" o "Reprobado" en un segundo Label.

Errores frecuentes

ErrorCausa y solución
FormatExceptionConvertiste texto vacío o con letras. Usa TryParse.
NullReferenceExceptionUsas algo sin valor, por ejemplo SelectedItem sin selección. Revisa != null.
